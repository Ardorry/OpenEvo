# ChemBench Supervised Transfer V3 Result Package

This directory contains the compact public reporting package for the
ChemBench Supervised Transfer V3 campaign.

## Main report

`final-feasibility-package/ChemBench_STV3_最终会议汇报.md`

## Included

- aggregate metrics;
- category-level Test results;
- Train learning and transition summaries;
- paired Test flip analysis;
- final context-footprint statistics;
- selected formal monitoring summaries;
- integrity checksums.

## Excluded

The public Git package excludes:

- complete event streams;
- state databases;
- runtime-service logs;
- private manifests;
- question text, options and ground truth;
- model completions and transcripts;
- credentials and provider headers;
- complete Core workspaces.

## Interpretation boundary

This campaign reused the official ChemBench pool and cannot establish strict
historical never-exposure or external-independent generalization.
