# Archive Policy

## Stored in Git

This directory contains compact and reviewable public evidence:

- final reports;
- aggregate metrics;
- category-level tables;
- plots;
- selected monitoring summaries;
- code identity;
- SHA-256 checksums.

## Stored outside Git

The complete local experiment archive retains:

- full event streams;
- state databases;
- runtime-service logs;
- private manifests;
- evaluator-private state;
- model completions and transcripts;
- credentials and provider headers;
- complete Core workspaces.

The external archive is intentionally omitted from the public repository.
