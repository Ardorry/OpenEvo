# Runtime downloads

ChemCrowRun uses the Linux amd64 science runtime published with the project:

- [Runtime OCI archive](https://github.com/Ardorry/OpenEvo/releases/download/chemcrowrun-runtime-0.1.1/openevo-science-runtime-0.1.1-linux-amd64.tar.gz)
- [Source and license package](https://github.com/Ardorry/OpenEvo/releases/download/chemcrowrun-runtime-0.1.1/chemcrowrun-runtime-sources-and-licenses.tar.gz)
- [Release page](https://github.com/Ardorry/OpenEvo/releases/tag/chemcrowrun-runtime-0.1.1)

Load the runtime with:

~~~bash
docker load --input openevo-science-runtime-0.1.1-linux-amd64.tar.gz
~~~
