# Format-only submission example

`FORMAT_ONLY.synthetic-submission.json` is synthetic schema demonstration data generated from
unit-test fixtures. It is **not an experiment, not a passing audit, and not eligible for a leaderboard**.
Its scores, IDs and hashes are placeholders. The literal PASS field demonstrates the schema's
required shape only; it is not supported by real evidence. Actual submissions must be generated by
`chemcrowrun report` from a fresh, sealed, fully audited 14-task experiment.
