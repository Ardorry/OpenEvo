# Memory

- For alkene + HBr questions, explicitly separate the normal ionic pathway from the peroxide-promoted radical pathway.
- Validate alkene structure first, especially whether the double bond is exocyclic or endocyclic, because this controls which intermediate is more substituted.
- Without peroxide, use Markovnikov addition: protonation should generate the more stable carbocation, then bromide attacks.
- With peroxide, apply the peroxide effect only to HBr: peroxide acts as a radical initiator, is not incorporated into the product, and favors bromine addition at the position that gives the more stable carbon radical.
- Compare products by stating where bromine and hydrogen add in each mechanism, not just by naming products.
- Always check whether either product creates a stereocenter; if so, mention that a racemic or stereochemical mixture is expected absent stereocontrol.
- When using chemistry software or tool output, present it as observational evidence only and reconcile it with standard organic mechanism reasoning.
