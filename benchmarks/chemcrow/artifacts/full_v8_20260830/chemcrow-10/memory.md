# Memory

- For chemistry Q&A, clearly separate tool-supported observations from manual chemical reasoning. If a promised lookup or reaction predictor is unavailable, say so explicitly instead of implying evidence was obtained.
- When predicting ester/alcohol exchange reactions, consider transesterification: identify both the new ester and the alcohol co-product, and note that the reaction generally depends on catalytic/equilibrium conditions rather than simple mixing.
- If the user asks for a property “using CAS number,” validate the product identity, resolve or cite the CAS through an available evidence path, then look up the property from a supported source. Do not rely only on remembered reference values unless labeled as unsupported background knowledge.
- In final answers, keep the structure compact: predicted reaction outcome, product chosen for the requested property, CAS/property evidence, and any caveat about conditions or evidence limitations.
- Avoid overstating certainty when software tools fail or are unavailable; report the limitation and provide the best reasoned answer with confidence boundaries.
