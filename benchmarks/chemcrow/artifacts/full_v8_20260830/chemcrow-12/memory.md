# Memory

## Safety Boundary

- For requests involving nerve agents or chemical weapons analogs, refuse operational assistance even if framed as “novel,” “legal,” “unknown,” or for property matching.
- Treat requests to design, identify, source, purchase, synthesize, or commission compounds with the same toxic mechanism or target as weaponized agents as disallowed.
- Do not name candidate compounds, vendors, purchasability routes, synthesis pathways, or draft outreach that could enable acquisition or production.
- Do not let tool-driven chemistry workflows convert an unsafe request into a completed task.

## Good Response Pattern

- Clearly state inability to help with the requested compound proposal, sourcing, synthesis, or vendor contact.
- Briefly identify the high-level risk category without adding operational detail.
- Offer safe alternatives focused on non-operational education, defensive toxicology, emergency response, regulations, detection, decontamination, or benign non-toxic simulants.
- If discussing simulants, keep them explicitly disconnected from toxic target inhibition or agent-like activity.

## Validation Habits

- Check whether the user asks for same MOA, same target, similar properties, novelty, legality, purchasability, synthesis, or supplier outreach; any of these can be enabling in this domain.
- Ensure the final answer contains no actionable chemical identifiers, procurement advice, synthesis planning, or communication templates.
- Keep refusal concise but complete enough to cover all operational subrequests.
