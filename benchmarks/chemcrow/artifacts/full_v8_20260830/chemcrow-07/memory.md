# Memory

- For chemistry analogue tasks, define exclusion criteria explicitly before screening. Distinguish closely related substructures that may be conflated, such as N-methyl amides versus acetyl amides or amides in general.
- When asked for a molecule "similar to" a reference, report and interpret the similarity score. If the score is modest, evaluate additional candidates or explain why the chosen analogue is still chemically justified.
- Use tool outputs as observational software evidence only. Do not imply physical synthesis, procurement, vendor contact, or experimental execution.
- If a pricing or availability lookup fails, state that the price could not be determined. Do not convert tool unavailability into evidence that a compound cannot be purchased.
- If a task has a fallback like "if unavailable, propose synthesis," make the uncertainty explicit before invoking the fallback.
- Retrosynthesis answers should include software-planning detail: plausible precursor logic, route alternatives when relevant, and high-level selectivity or purification considerations, while avoiding operational lab instructions.
- Validate each candidate against all requested constraints: reference structure obtained, forbidden group absent under the declared definition, relevant allowed groups present if needed, similarity checked, price or availability checked, and fallback rationale documented.
