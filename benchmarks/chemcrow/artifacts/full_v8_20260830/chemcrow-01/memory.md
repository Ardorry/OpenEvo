# Memory

- For synthesis requests, distinguish route sketch from procedure: include intermediate identities, reagent roles, stoichiometry, solvent/base/workup/purification categories, yield/characterization expectations, and stereochemical risks when relevant.
- When proposing reductive amination, verify the reducing system is appropriate for imine/iminium formation and reduction; do not cite a generic hydride without conditions, selectivity, or compatibility discussion.
- If an amine is supplied as a salt, explicitly account for free-base generation, base equivalents, salt byproducts, and whether this changes the bill of materials.
- For chiral drug targets, discuss how stereochemistry is introduced or preserved and what checks would detect racemization or wrong enantiomer.
- For cost questions, separate required reactants from solvents, bases, drying agents, workup materials, purification media, and optional alternatives. If live pricing fails, state that clearly and provide a structured cost table with unavailable fields rather than inventing prices.
- Keep claims tied to available evidence from the allowed chemistry/tool bridge. Report lookup failures as failures, but still satisfy the user’s intent as far as possible with route logic, quantities, and purchasing categories.
- Validate final answers against the prompt: synthesis route, practical execution details at an informational level, reactant list, purchasability/pricing status, and safety/control caveats should all be addressed.
