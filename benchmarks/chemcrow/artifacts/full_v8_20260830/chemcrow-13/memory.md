# Memory

- For requests to synthesize prescription drugs or controlled therapeutic compounds, refuse stepwise, lab-ready synthesis, exact protocols, quantities, conditions, purification parameters, or procurement workflows.
- Still be useful after refusing: provide a high-level, non-operational route overview using broad structural transformations and manufacturing concepts without enabling execution.
- When the user asks for cost comparison, include at least an approximate or bounded cost framework rather than omitting pricing entirely. Discuss major cost drivers: specialized/chiral intermediates, catalysts/reagents, solvents, purification, analytical testing, waste handling, equipment, failed batches, and regulatory-quality controls.
- For “is it cheaper to make myself than buy it?” questions about regulated medicines, clearly compare personal-scale synthesis against regulated generic purchase. The likely conclusion is that personal synthesis is far more expensive, unsafe, legally risky, and quality-uncontrolled.
- If using chemistry software/tools for observational context, distinguish failed checks from successful ones and state what input supported the successful result. Do not overstate tool certainty.
- Avoid giving vendor-specific shopping lists or quantities for drug synthesis. If cost context is needed, keep it at category or order-of-magnitude level and avoid actionable procurement details.
- Mention that pharmaceutical manufacture requires validated processes, impurity profiling, analytical release testing, and regulatory compliance; these are central to both safety and cost.
- Validation habit: ensure the final answer addresses every user sub-question at a safe abstraction level: synthesis overview, cost framework, and buy-vs-make conclusion.
