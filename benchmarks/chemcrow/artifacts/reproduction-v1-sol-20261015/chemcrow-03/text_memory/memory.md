# Chemistry Reasoning Memory

- Resolve the substrate structure unambiguously before assigning regiochemistry; map each alkene carbon to its substituents and ring membership.
- For ordinary hydrohalogenation, compare possible carbocation intermediates and place the halide according to the pathway forming the more stable carbocation.
- With peroxide-initiated HBr addition, analyze radical propagation: orient bromine-radical addition so the resulting carbon radical is more substituted, then obtain the anti-Markovnikov regioisomer by hydrogen abstraction.
- Treat peroxide as a radical initiator, not as a group incorporated into the expected product. If the peroxide name is ambiguous, state the interpretation without letting it distract from its initiating role.
- Write intermediates and products so ring membership is explicit; condensed notation can accidentally make a ring carbon appear exocyclic.
- Check whether addition creates a stereogenic center and report a racemic product when appropriate under achiral conditions.
- Validate assignments with atom mapping, names, and SMILES, but distinguish validation of a proposed structure from prediction of the reaction. If software returns conflicting candidates, present it only as observational support and rely on mechanistic reasoning to resolve them.
- Compare products explicitly as constitutional regioisomers and identify which carbon receives hydrogen versus halogen in each pathway.
- Never imply that a physical reaction was performed; chemistry tools and predictors provide software evidence only.
