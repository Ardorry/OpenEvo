# Chemistry Task Memory

- Balance the reaction before selecting a predicted product. Prefer atom-balanced product sets over a model’s top-ranked but incomplete prediction.
- For transesterification and similar exchange reactions, explicitly identify all products and note equilibrium or condition dependence when relevant.
- Resolve each product independently to an unambiguous structure, systematic name, and CAS number.
- Report a property as “looked up by CAS” only when the tool successfully returns that property for that identifier. Identity-only pages and failed requests are not verification.
- Keep sourced facts distinct from chemical inference. If reliable property evidence is unavailable, state that limitation rather than presenting an unsupported value.
- Cross-check predicted products for atom conservation, plausible functional-group changes, and missing coproducts.
- Treat chemistry-tool output as software evidence only; never imply physical execution, procurement, or experimental confirmation.
