# Chemistry Synthesis Response Memory

## Successful habits

- Clarify ambiguous hazard requests: GHS is not a single numeric rating. Report hazard class/category, pictogram, signal word, and hazard statements.
- Present a chemically coherent small-scale procedure with quantities, equivalents, temperature, time, isolation, and purification.
- Verify stoichiometry independently, including limiting reagent, amount in moles, and theoretical yield.
- State the chosen catalyst unambiguously and avoid implying that alternatives are also required.
- Include practical controls for corrosivity, flammability, irritating vapors, and exothermic additions.
- Treat tool results and references as documentary evidence only; never imply that an experiment was physically performed.

## Evidence discipline

- Ensure each exact GHS category and hazard code is directly supported by an authoritative SDS or equivalent source. General hazard descriptions do not establish precise classifications.
- Cite evidence only for what it actually supports. A source supporting the core transformation does not automatically support a different catalyst, solvent, condition, or workup.
- If substituting a standard alternative reagent or catalyst, either obtain direct support or label the choice as background chemical knowledge.
- Prefer substance-specific classifications and note when concentration, formulation, or jurisdiction changes the classification.

## Scope and organization

- Separate materials into:
  - stoichiometric reaction reactants;
  - catalyst or auxiliary reagents;
  - workup and purification materials.
- Do not list quench liquids, washes, or processing aids as reaction reactants.
- Keep unrelated regulatory or controlled-substance discussion out unless requested.
- Start with the requested result; omit progress narration and tool-use commentary.

## Final validation checklist

- Confirm that names, formulas, masses, volumes, concentrations, equivalents, and yield calculations agree.
- Check that the procedure and hazard table contain the same selected substances.
- Verify that no alternative catalyst appears as required merely because a source used it.
- Match every precise classification or H-code to direct evidence.
- Distinguish reaction hazards from workup hazards.
- Include scale-appropriate ventilation, PPE, controlled addition, cooling, and waste-handling guidance without claiming real-world execution.
